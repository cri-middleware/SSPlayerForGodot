{#- The header's language selector, overridden so that switching language keeps you on the page you are reading instead of dumping you on the other locale's home page. Each locale is built from its own config, and the stock partial just emits `alt.link` as written, so this rebuilds the href from the current `page.url`. Two config values feed it: extra.alternate[].link the locale's subpath under the site root -- "" for English, "ja/" for Japanese. NOT a full URL, unlike stock Material. extra.site_root_prefix how to get from *this* build's site root back up to the root of the whole multi-locale site -- "" for English (it is the root), "../" for Japanese (it builds into site/ja). So the target is ``, handed to `url`, which makes it relative to the page being rendered. Everything stays relative, so the site works under any path prefix and on a plain `python -m http.server`. Keep this file identical across the repositories that carry it. -#}
